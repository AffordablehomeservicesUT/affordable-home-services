# Affordable Home Services — Website (Homepage V1)

This folder contains the source code for the Affordable Home Services
website, built with Next.js (a website framework), following the approved
Stage 3 (Homepage Blueprint) and Stage 4 (Homepage Content & Photography
Plan) documents.

**What's built so far:** the homepage and the shared header/footer used on
every page. Individual service pages (Christmas Lighting, Permanent
Lighting, etc.) have not been built yet — those are a later stage.

**Photos:** real project photography has not been added to this folder yet.
Every photo spot on the homepage currently shows a labeled gray placeholder
box telling you exactly which approved photo belongs there. See
`/public/images/README.md` for the full photo-by-photo guide.

**The Jobber quote form:** not yet connected. The "Get a Free Quote" buttons
currently point to a `/request-quote` page that hasn't been built yet — that
happens in a later stage, alongside the Jobber integration.

You do not need to understand any of the code in this folder. Claude will
walk you through exactly what to click, upload, or approve at each step.
