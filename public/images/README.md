instead of photos — this is intentional so nothing fake or AI-generated is
used in their place.

## How to actually add a photo (no coding required)

1. Resize or export the photo as a .jpg (most phone/camera photos already
   work fine as-is).
2. Give it the exact filename shown above (lowercase, dashes instead of
   spaces).
3. Upload it into the matching folder above, either by dragging it into
   the folder on GitHub's website, or by asking me to wire it in once
   you've shared the file with me.
4. Let me know it's been added — I'll update the corresponding component
   to display the real photo instead of the placeholder box.
